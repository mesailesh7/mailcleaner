MailCleaner Cross-Platform Guide

MailCleaner is an intelligent, offline inbox cleaner running locally on Windows, macOS, and Linux.

Google / Gmail Setup

  1. Open Google Account Security settings.
  2. Ensure 2-Step Verification is active.
  3. Search for "App passwords".
  4. Create a password named "MailCleaner".
  5. Paste the 16-character code as your password.

Apple / iCloud Setup

  1. Log in to appleid.apple.com.
  2. Navigate to Sign-In and Security.
  3. Select App-Specific Passwords.
  4. Generate a key for MailCleaner.
  5. Host is set to imap.mail.me.com on port 993.

Security & Privacy

  • 100% offline local classification via Laya.
  • No email content ever sent to third-party APIs.
  • App passwords stored locally with Fernet encryption.
  • Dry-run mode by default prevents unintended changes.
